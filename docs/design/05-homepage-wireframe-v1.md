## Mobile behavior

- Navigation collapses into an accessible disclosure menu.
- Hero copy remains the first meaningful content.
- Product cards become a single-column stack.
- Call-to-action buttons remain full-width when necessary.
- No horizontal overflow is permitted.
- The theme control remains keyboard accessible.
