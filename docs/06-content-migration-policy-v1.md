## Rules

1. Nothing is deleted automatically.
2. Every existing page and post receives exactly one reviewed disposition:
   - KEEP
   - REWRITE
   - MERGE
   - ARCHIVE
   - REDIRECT
   - REMOVE_AFTER_APPROVAL
3. A redirect destination must be approved and tested before a legacy route is removed.
4. Taxonomy cleanup is review-based; zero-count terms are not automatically deleted.
5. Public media binaries are not downloaded or migrated in this stage.
6. The confirmed non-returned media ordinal is preserved as evidence; no missing ID is fabricated.
7. Media alt text is rewritten based on actual visual purpose, not generated in bulk without review.
8. Claims, metrics, client names and testimonials require evidence and approval before publication.
9. Production content remains unchanged until Preview, product tests, PR review and release gates pass.
