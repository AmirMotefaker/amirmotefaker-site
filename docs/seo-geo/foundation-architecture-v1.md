# AmirMotefaker.ir SEO + GEO Foundation v1

## Goal
Build a unified discovery layer for traditional search engines and generative AI engines.

## Architecture

### SEO Layer
- Metadata generation per locale
- Canonical URL strategy
- Hreflang mapping for fa/en
- Sitemap and robots optimization
- OpenGraph social previews
- Internal linking model

### GEO Layer
- Founder entity model
- Organization entity model
- Product entity model
- FAQ-ready content blocks
- AI-readable structured content
- Citation-oriented pages

## Entity Model

Amir Motefaker
- Person
- Founder profile
- Technology narrative

Products
- Product entity
- Description
- Category
- Use cases
- Related projects

## Implementation Order

1. Metadata foundation
2. Structured data layer
3. Entity registry
4. Product authority pages
5. AI-readable content endpoints
6. Measurement layer

## Acceptance Criteria

- Persian and English pages share a consistent SEO/GEO architecture.
- Structured data validates correctly.
- Production changes only happen after PR review and release.
