# AmirMotefaker.ir Technical SEO Foundation v1

## Objective
Build the technical SEO foundation required for strong search visibility and GEO readiness.

## Scope

### 1. Metadata System
- Audit title and description coverage
- Ensure localized metadata strategy for FA/EN pages
- Define reusable metadata conventions

### 2. Indexing Infrastructure
- robots.txt validation
- sitemap.xml validation
- canonical URL strategy
- locale-aware indexing rules

### 3. Structured Data
- Person schema for Amir Motefaker
- Organization schema
- Product schema for portfolio products
- Website and breadcrumb schema

### 4. Performance
- Core Web Vitals baseline
- Image optimization review
- JavaScript and rendering review

### 5. Internal Linking
- Founder page connections
- Product authority page connections
- Content knowledge graph preparation

## Acceptance Criteria
- All public FA/EN routes have SEO-ready metadata
- Structured data strategy documented
- Technical SEO checklist completed
- Foundation ready for GEO implementation
