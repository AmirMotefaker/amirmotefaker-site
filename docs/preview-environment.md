# Stable preview environment

The canonical non-production review hostname for AmirMotefaker.ir is:

- `https://preview.amirmotefaker.ir`

This hostname is reserved for validating changes before production release. Production DNS, routing, and the live `amirmotefaker.ir` site must remain unchanged while preview QA is in progress.

Current preview QA scope includes localized FA/EN routes, all 11 product authority pages, Technology News article routing, SEO/GEO metadata and structured data, and responsive checks.
