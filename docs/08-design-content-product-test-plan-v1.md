# AmirMotefaker.ir — Design and Content Product Test Plan V1

## Automated prototype checks

- Required prototype files exist.
- HTML language is Persian and direction is RTL.
- Exactly one H1 exists.
- Meta description exists.
- Canonical URL exists.
- Viewport metadata exists.
- Approved positioning message is present.
- Primary and secondary calls to action are present.
- LinkResan, Farsi Smart and Ava appear in the approved order.
- Production and Discovery statuses are represented without unsupported metrics.
- Dark mode exists.
- Reduced-motion handling exists.
- No gradient styling exists.
- No external script, stylesheet or image dependency exists.
- No iframe, tracking request, fetch or XMLHttpRequest exists.
- No placeholder copy exists.
- No Production mutation is performed.

## Manual visual review

- Typography hierarchy is clear in Persian.
- Section rhythm and whitespace feel intentional.
- Product priority is visually obvious.
- CTA hierarchy is obvious.
- Mobile layout has no horizontal overflow.
- Keyboard focus states are visible.
- Light and dark themes remain readable.
- Copy does not make unsupported performance, revenue or market claims.
- Product screenshots are not approved until real evidence is supplied.
