# ADR-001 Modern Next.js AI Platform

## Status
Accepted

## Context
AmirMotefaker.ir is migrating from WordPress to a modern AI Founder Platform.

## Decision
Use:
- Next.js
- React
- TypeScript
- Tailwind CSS
- MDX Content
- GitHub CI/CD

## Reasons
- Better performance
- Modern UX
- Full design control
- AI workflow integration

## Migration
Previous WordPress implementation is archived.
New implementation starts from apps/web.
