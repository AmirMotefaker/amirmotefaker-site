# Design Tokens

## Dark

- Canvas: `#05070D`
- Surface: `#0B1220`
- Strong surface: `#111A2E`
- Primary text: `#F8FAFC`
- Secondary text: `#CBD5E1`

## Accent

- Green: `#22C55E`
- Purple: `#8B5CF6`

## Usage ratio

The interface is neutral-first. Green is the primary accent and purple is limited to focus, outlines and restrained emphasis.
